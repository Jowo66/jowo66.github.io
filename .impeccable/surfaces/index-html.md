# Landing page (index.html)

Scope: the root landing page. Mode: Experience. Audience: recruiters skimming for co-op and internship hires. Job: see real work in the first viewport, then reach a project, GitHub or contact. Constraints: no invented facts; missing facts stay hidden; keep the EN/FR/ES translator and a one-click route to Neo-Jowo OS.

Unresolved: school, program, year, email, LinkedIn, photo, resume PDF.

## Direction contract

THESIS: The page is a set of stills from the work, shown the way a cinema shows lobby cards. It refuses the student-portfolio default of avatar, greeting, skill chips and a grid of equal cards.

OWN-WORLD: Haze-lilac ground (#ebe8f1), aubergine ink (#1c1330), lantern vermilion (#c5301a) owning whole regions: the caption strip rules, the primary action and the entire contact band. Every project is a still with a condensed-caps caption strip beneath it. Bricolage Grotesque sets names and text; Barlow Condensed sets caption strips. Square corners, no cards, no glow.

STORY: The visitor sees the alley first, learns whose it is, reads what was built and how, and leaves through a project, GitHub or the contact band.

FIRST VIEWPORT: A full-bleed still of the alley fills the top two thirds. Navigation sits on the still. Below it a caption strip: the name at display size on the left, one sentence and two actions on the right. The primary action, "Run it here", wakes the still into the live alley in place.

FORM: Cinema lobby-card set, position 6 of 7 on the grounded list. seed:e5afb2584c96d1d0. The roll ran degraded (no challengers).

Signature interaction: the hero still wakes into the running alley inside its own frame. Motion grammar: one letterbox reveal of the hero on load, exponential ease-out; nothing else animates on entrance.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
